# Benchmarking de competidores

**Issues:** JUA-51 (incorporación de hallazgos) y JUA-60 (archivo y actualización).
**Propósito:** reunir los análisis de productos cercanos a Consona y lo que se decidió a partir de ellos.
**Naturaleza:** documentación exploratoria. Un benchmarking no es una decisión de producto: las decisiones vigentes están en ADR-001, ADR-002, la línea base y Linear.

## Reglas

1. **El repositorio es público.** Solo enlaces a material de los competidores: sin copias de sus textos, capturas ni documentos.
2. **Datos sin verificar, marcados.** Las cifras de tiendas, precios, fechas y funciones cambian. No se citan como evidencia externa sin comprobarlas.
3. **El original no se reescribe.** Las correcciones y decisiones posteriores se añaden como notas de contraste, con fecha.
4. **La auditoría práctica usa perfiles ficticios.** Nunca datos reales de nadie. Las capturas se guardan fuera del repositorio.
