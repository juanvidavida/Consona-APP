# Historial del contrato taxonómico local de Consona

## [1.0.0] — Candidato de revisión

- Se introduce un contrato candidato de P1 para categorías locales futuras de experiencias físicas, emocionales y cognitivas.
- Se fija la escala candidata de intensidad: `not_present`, `mild`, `moderate`, `intense` y `not_applicable`.
- Se limita la fuente estructural v1 a `self_report` y se reserva `partner_observation` para una decisión posterior condicionada.
- Se añaden un esquema técnico con `additionalProperties: false`, fixtures sintéticos válidos e inválidos y una validación local sin dependencias externas.
- Se publica una lista explícita de campos, fuentes, conceptos y salidas prohibidos.
- No se añade captura, almacenamiento, fechas, cálculo de fase, red, cuenta, sincronización, analítica, telemetría ni datos personales reales.

> Esta versión no está aprobada. Un cambio posterior exige revisión de producto, privacidad y contenido, actualización de trazabilidad y pruebas de regresión.
